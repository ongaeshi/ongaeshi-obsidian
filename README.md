# ongaeshi-obsidian

私の個人的な [Obsidian](https://obsidian.md/) のVault（保管庫）テンプレートです。主に以下の要素を記録します。

1. デイリーノートとウィークリーノート（ライフログ）
2. タスク（TODOリスト）
3. 既読管理（今読んでいる文献）
4. メディア管理（書籍、音楽、漫画、ゲーム、映像など）
5. 永続メモ（Zettelkasten の Permanent notes）

これは決して教条的な（押し付けがましい）ものではなく、あくまで Obsidian の使い方の一例に過ぎません。気に入った部分を取り入れて、ご自身のニーズに合わせてカスタマイズしてください。

このVault構造の詳しい説明については、私のサイトの記事 [いまから書きます...](https://ongaeshi.hatenablog.com/) をご覧ください。

※ ご推察の通り、このレポジトリは [kepano-obsidian](https://github.com/kepano/kepano-obsidian/) から強い影響を受けています。

## フォルダ構造

本リポジトリは以下のようなフォルダ構造を前提としています。

- **`01_Inbox`**: 新規ノートが最初に配置される場所です。未整理のアイデアやWebクリップなどの一時置き場として機能します。
- **`02_Daily`**: デイリーノートとウィークリーノートを格納する場所です。日々の記録やタスクがここに集約されます。
- **`03_Project` 〜 `06_Archive`**: PARAメソッド（Project, Area, Resource, Archive）に基づくデータ置き場です。個人のプロジェクトや資料など、用途に応じて任意で活用します。
- **`07_Thinking`**: 永続メモが格納される場所です。日々の記録や文献から得た知識を昇華させ、思考の結晶として一生残る形にまとめたメモを保存します。

数字は[クイックスイッチャー](https://obsidian.md/ja/help/plugins/quick-switcher)での絞り込みを容易にするために付けてあります。例えば、`72ノート`のように入力することで、`07_Thinking/02_永続メモ/Zettelkastenは理解を促進させるためのノート術である`を確実に開くことができます。

## 主な機能とデータ構造
### デイリーノート
日々の記録のベースとなるノートです。(`02_Daily/2026/W32` のように年と週番号のフォルダの下に配置します)
- **自動リンク**: ファイル名（`YYYY-MM-DD`）から前日のノートへのリンクを自動生成し、連続した記録をサポートします。
- **タスク管理**: その週のウィークリーノートからTODOを埋め込み、日々のタスクの確認漏れを防ぎます。
- **睡眠＆トレーニング記録**: 睡眠時間や日々の習慣（トレーニングなど）のプロパティを記録し、ウィークリーノートでの集計に利用します。

### ウィークリーノート
1週間の振り返りとタスク管理を行うノートです。(`GGGG-Www` 形式で作成します)
- **今週のTODO**: その週にやるべきTODOを管理し、デイリーノートに表示します。
- **デイリーノート一覧**: DataviewJSを用いて、その週のデイリーノート一覧を自動で抽出し表示します。
- **睡眠時間の集計・グラフ化**: デイリーノートに記録された「睡眠時間」を集計し、平均時間の算出やグラフ化（折れ線グラフ）を自動で行います。

### TODO
タスクを単一のノート単位で柔軟に管理します。
- `TODOテンプレート` を使用して作成し、カテゴリプロパティ（`categories: "[[TODO]]"`）を付与します。
- 作成日（`created`）と完了日（`finished`）のプロパティでタスクのライフサイクルを管理します。
- `Categories/TODO.md` のビューから、未完了のTODOやこれまでの全TODOを一覧で確認・管理することができます。

### 既読管理
読書中の本や、読んでいる途中の記事・Webページなどの進捗を管理します。
- カテゴリプロパティに `"[[読んでる]]"` を付与して管理します。
- TODOと同様に作成日と完了日で進捗を管理し、`Categories/読んでる.md` のビューから「現在読んでいるもの」と「読み終わったもの」を一覧表示できます。

### メディア管理
書籍、音楽、漫画など、体験したメディアの記録と評価を行うシステムです。
- カテゴリに `"[[メディア]]" を付与し、種類（`kind`）、著者・アーティスト（`author`）、評価（`rating`）などのプロパティを記録します。
- `Categories/メディア.md` のビューを使用することで、今年触れたメディアの振り返り、種類別（書籍・音楽・漫画）の一覧表示、評価順の並び替えなどが簡単に行えます。

### 永続メモ
日々の思いつきや文献から得た知識を、一生残る形に昇華させたメモです。
- `07_Thinking/02_永続メモ/` 以下に配置し、思考の結晶として蓄積します。
- `永続メモテンプレート` を使用して作成し、カテゴリ（`categories: "[[永続メモ]]"`）を付与します。
- 単なる思い付き（`01_思い付きメモ`）や文献のメモ（`00_文献メモ`）から発展させ、自分の知識ネットワークを構築するためのノートです。

## 使用プラグイン
- [Templater](https://github.com/SilentVoid13/Templater)
    - 日付の自動計算や、TODO・デイリー・ウィークリーなどの各種テンプレートの展開に使用します。
- [Dataview](https://github.com/blacksmithgu/obsidian-dataview)
    - デイリーノートの集計や睡眠時間のグラフ化（DataviewJS）に使用します。
- [Previsous River](https://github.com/ongaeshi/obsidian-previous-river)
    - `previous` プロパティが設定されたノート（デイリーノートやウィークリーノート）を前後にスムーズに移動するために使用します。

## 使い方
1. 本リポジトリのフォルダ構成とテンプレートファイルを Obsidian のVaultに配置します。
2. Templater の設定で、新しいファイル作成時に自動的にテンプレートを適用するように設定するか、手動でテンプレートを挿入します。
3. ノート作成時は適切なテンプレートを使用し、日々の記録や各データの管理は `Categories/` フォルダ内の各種ビューから行います。
